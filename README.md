## Features

- Sidebar tab navigation
- Bookmarks, History, Downloads manager
- Dark and Light mode
- Find in page (Ctrl+F)
- Zoom controls
- Custom search engine (Google, DuckDuckGo, Bing)
- Privacy-focused — no telemetry, no tracking
